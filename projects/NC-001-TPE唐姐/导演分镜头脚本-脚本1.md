## 整体拍摄要求

1. **拍摄顺序：** 按分镜头序号从1到5依次拍摄
2. **每条重拍次数：** 镜头1建议3-5条，其余2-3条，选最佳保一条
3. **设备要求：** 1080P以上，4K更佳；手机拍摄需稳定器
4. **收音要求：** 外接麦克风，禁止手机/相机内置收音
5. **画面风格：** 真实感，不开美颜，自然光或专业补光
6. **横竖选择：** 抖音竖屏（9:16），快手同步

## 摄影师注意事项（全部）

### 设备设置
- [ ] 分辨率：1920×1080（竖屏9:16）以上
- [ ] 帧率：30fps或60fps均可
- [ ] 稳定器：手机拍摄必须使用，手机直立手持会导致画面晃动
- [ ] 对焦：设置为"脸部优先"或手动对焦到唐姐面部
- [ ] 曝光：锁定曝光，避免自动切换导致画面闪烁

### 收音设备
- [ ] 外接麦克风（领夹麦或枪式麦）已连接并测试
- [ ] 录音电平：录制前测试音量，确保无爆音
- [ ] 备用电池：麦克风备用电池已准备
- [ ] 监听：如有耳机监听，录制中全程佩戴

### 拍摄环境
- [ ] 光线：自然光充足或补光灯已调好；避免背光（唐姐面部无阴影）
- [ ] 背景：门市部货架/样品架整洁入镜，无无关杂物
- [ ] 环境音：风扇/空调噪音评估，必要时关闭或另外处理
- [ ] 手机静音：拍摄前确认手机/其他设备静音，避免来电打扰

### 唐姐状态
- [ ] 开拍前让唐姐熟悉完整口播内容，但不要求背诵
- [ ] 唐姐知道每个镜头的情绪要求（参考"情绪表情"栏）
- [ ] 确认唐姐知道这是"第1集"，未来会有续集
- [ ] 每条拍摄间隙给唐姐30秒调整状态，不要连续拍摄超过10条

### 素材管理
- [ ] 每条素材标注：集数_镜头序号_序号（如 NC001_L1_V1）
- [ ] 拍摄完毕后检查所有素材是否完整播放
- [ ] 收音质量：回放3-5条确认声音清晰无杂音
- [ ] 备用：至少保留2条完整可用的各镜头素材

## 导演备注（红华编导）

1. **最重要的一条：** 镜头1的开场表情，这是整条视频的"门面"，如果唐姐状态不对，先停下来聊聊天，找回真实感再继续
2. **节奏感：** 制造业老板喜欢"听干货"，所以语速可以偏慢，不要急
3. **样品展示：** 这是建立专业信任的关键，样品一定要真实、干净、有关联性（与口播中的应用场景匹配）
4. **结尾引导：** 点关注要自然，唐姐可以理解成"老客户介绍新客户"的感觉，而不是"求点赞"
