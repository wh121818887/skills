## 整体拍摄要求

1. **拍摄顺序：** 按分镜头序号从1到4依次拍摄
2. **每条重拍次数：** 镜头1建议3-5条，其余2-3条，选最佳保一条
3. **设备要求：** 1080P以上，4K更佳；手机拍摄需稳定器
4. **收音要求：** 外接麦克风，禁止手机/相机内置收音
5. **画面风格：** 真实感，不开美颜，自然光或专业补光
6. **横竖选择：** 抖音竖屏（9:16），快手同步
7. **特殊说明：** 本集可以手持跟拍移动镜头，营造"带领参观"的临场感

## 摄影师注意事项（全部）

### 设备设置
- [ ] 分辨率：1920×1080（竖屏9:16）以上
- [ ] 帧率：30fps或60fps均可
- [ ] 稳定器：手机拍摄必须使用
- [ ] 对焦：设置为"脸部优先"
- [ ] 曝光：锁定曝光

### 收音设备
- [ ] 外接麦克风（领夹麦或枪式麦）已连接并测试
- [ ] 录音电平：录制前测试音量
- [ ] 备用电池：麦克风备用电池已准备

### 拍摄环境
- [ ] 光线：自然光充足或补光灯已调好；避免背光
- [ ] 背景：门市部货架/产品整洁入镜，无无关杂物
- [ ] 环境音：风扇/空调噪音评估

### 唐姐状态
- [ ] 本集唐姐要有"坦诚自信"的感觉，不是"推销"，而是"邀请"
- [ ] 镜头3是本集情感核心，要有"真的在乎客户的时间"的感觉
- [ ] 镜头4结尾"下期工厂实拍见"要自然，不能太广告腔

### 本集特殊说明
- [ ] 本集可以不用额外道具，唐姐本人+门市部背景即可
- [ ] 镜头2可以用手持跟拍方式，让画面有"参观引导"的临场感

## 导演备注（红华编导）

1. **本集核心转化点：** 把"工厂不常拍"这个客观限制，转化成"先看产品、再看工厂"的服务流程。逻辑是：产品看懂了→信任建立→邀请看厂验证
2. **情绪关键：** 唐姐不是在"推销工厂"，而是在"帮客户把关"。逻辑是"你来了才不会被坑"
3. **前置联动：** 三集逻辑——脚本1：别问价格先说需求 → 脚本2：材料差异决定价格 → 脚本3：来工厂验证实力
4. **悬念预告：** 结尾"下期工厂实拍见"，暗示下集会带观众进工厂参观，为脚本4（工厂进厂型）埋伏笔
5. **真实感来源：** 唐姐可以说"我不是不想让你看工厂，是因为我觉得你来了就要看有价值的东西"
