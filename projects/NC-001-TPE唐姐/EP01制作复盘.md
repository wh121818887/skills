## 一、制作流程（SOP）

### 步骤1：素材接收与检查

**输入**：客户提供的原始视频文件

**检查项**：
- [ ] 视频格式（MP4 / MOV）
- [ ] 分辨率（是否竖屏）
- [ ] 时长
- [ ] 是否多段（1-N段）
- [ ] 每段的音频是否清晰

**输出**：记录到项目文件夹 `raw/`

---

### 步骤2：音频提取

**工具**：`ffmpeg -i input.mp4 -vn -acodec pcm_s16le -ar 16000 -ac 1 output.wav`

**要点**：
- 采样率16kHz（whisper推荐）
- 单声道
- 多段视频分别提取

**输出**：`audio/original_L1.wav` 等

---

### 步骤3：音频清理（关键步骤）

**原则：先逐条处理，再拼装。绝对不能先拼装再处理！**

**操作**：
1. 逐条听每一段原始音频
2. 删除无效内容：
   - 321倒计时
   - 开场废话（"好，我们开始"之类）
   - 语气词（嗯、这个、那个、就是说）
   - 末尾废话
   - 静默超过0.5秒的部分
3. 确定每段的切点（精确到毫秒）
4. 确认每条干净后再进入下一步
5. 最后才拼装

**切点记录格式**：
```
L1: 删0.00-2.50s → 保留2.50-7.50s（5.00s）
L2: 删0.50-15.94s → 保留0.00-0.50s + 15.94s-end
```

**⚠️ 踩坑记录**：见本文档第三部分

**输出**：`trimmed/trim_L1.wav` 等

---

### 步骤4：音频拼接

**工具**：Python `pydub.AudioSegment`

**操作**：
- 按顺序拼接各段
- 计算总时长
- 验证总时长是否符合预期

**输出**：`EP01_trimmed.wav`

---

### 步骤5：字幕生成（Whisper转写）

**工具**：`faster-whisper`

**推荐配置**：
```python
model = faster_whisper.WordLevelTiming()
model.transcribe(
    audio_path,
    language="zh",
    word_timestamps=True,
)
```

**参数**：
- `initial_prompt`：可以加入专有名词（如"TPE"、"TPE材料"）提高识别准确率
- `word_timestamps=True`：获取词级时间戳（用于精确断句）

**输出**：
- 词级时间戳：`.json` 文件（包含每个字的时间戳）
- 转写文本：`.txt` 文件

---

### 步骤6：字幕断句与修正

**原则**：
- 按句子分段，每段不超过10字
- 问句、称呼可以单独成组
- 语气词可以单独成组
- 不要强行分开自然短语

**推荐分段规则**：
```
1. 标点符号（，。？！）是天然断点
2. 静音超过0.2秒也是断点
3. 每段字数上限10字（硬上限）
4. 问句结束于问号
5. "唐姐"等称呼可单独成组
```

**时间戳计算**：
- 用词级时间戳计算每段起止
- 保留3位小数（毫秒精度）
- 注意：标点符号不进入词级时间戳，计算时不要把标点算进去

**⚠️ 踩坑记录**：见本文档第三部分

**输出**：`.srt` 格式字幕文件

---

### 步骤7：字幕校验

**必检项**：
- [ ] 逐条核对文字是否准确
- [ ] 逐条核对时间戳是否正确
- [ ] 特别检查：
  - 开头是否有多余内容（321/你好等）
  - 结尾是否有残留
  - TPE、耐候性、汽车内饰等专业名词是否正确
- [ ] 检查是否有时间戳重叠
- [ ] 检查字幕是否在画面内（竖屏视频要验证MarginV）

**校验方法**：
1. 生成带字幕的视频
2. 截帧检查字幕位置
3. 用 `image` 工具分析截帧确认内容

---

### 步骤8：视频合成

**工具**：`ffmpeg`

**竖屏字幕参数（已验证可用）**：
```bash
ffmpeg -i input.mp4 \
  -vf "subtitles=subtitle.srt:force_style='FontName=Noto Sans CJK SC,FontSize=18,PrimaryColour=&H00FFFFFF,Alignment=2,Outline=1'" \
  -c:a copy \
  output.mp4
```

**关键参数**：
- `FontSize=18`：竖屏1080p下清晰可读
- `Alignment=2`：底部居中
- `Outline=1`：描边保证白字在任何背景下可见

**⚠️ 踩坑记录**：
- **不要乱调MarginV**：竖屏视频调MarginV容易把字幕移出画面
- `Alignment=2`（底部居中）已验证可用，不要改

**文件大小控制**：
- 飞书发送限制：尽量压到20MB以内
- 压缩命令：`ffmpeg -i input.mp4 -c:v libx264 -crf 28 -preset fast -c:a aac -b:a 128k output.mp4`

**输出**：`EP01_final.mp4`

## 三、踩坑记录（重要！）

### 坑1：先拼装再清理音频

**问题**：先把多段音频拼起来，再处理字幕。结果发现时间戳完全混乱，因为某一段开头有"321"这样的倒计时，删除后整段时间轴都要重新计算。

**教训**：**必须先逐条清理，再拼装**。每条素材确认干净了再进入下一步。

---

### 坑2：标点符号不进aligned word时间戳

**问题**：Whisper的`word_timestamps=True`返回的词级时间戳不包含标点符号（,，。？！等）。如果用标点位置去映射词级时间戳，位置总是差一位。

**表现**：字幕时间戳普遍偏早或偏晚1-2个字的时间。

**教训**：在遍历原文时就做切分，不要事后再用标点位置映射。正确做法：直接用转写出来的纯文字（去标点后）逐词匹配词级时间戳。

---

### 坑3：按标点分导致大量碎片

**问题**：最初按标点（逗号、句号）分句，导致大量2-4字的碎片字幕。

**原因**：中文口语里逗号用得很频繁，几乎每句话都有。

**教训**：
- 用0.2秒静音阈值 + 标点双重判断
- 10字上限但不要机械执行
- 问句、称呼、语气词可以单独成组
- 不要强行分开自然短语

---

### 坑4：L3字幕整体偏移1.2秒

**问题**：从第14段"不管你是说做玩具"开始，字幕快了1-2秒。

**原因**：多段素材各自有offset，计算时某段offset算错了。

**教训**：
- 多段素材每段都要单独计算offset
- offset = 前几段总时长（精确到小数点后3位）
- 调整后要重新生成SRT并截帧验证

---

### 坑5：竖屏视频MarginV设置

**问题**：竖屏1080x1920视频，想要把字幕放在中间偏上，调了MarginV结果字幕跑出画面了。

**原因**：ASS字幕的坐标系统里，MarginV在竖屏下的行为和横屏不同。

**教训**：
- 竖屏视频**不要乱调MarginV**
- 用`Alignment=2`（底部居中）已验证可用
- 如果一定要调位置，先截帧验证是否在画面内

---

### 坑6：faster-whisper输出格式差异

**问题**：不同版本的faster-whisper输出格式不同，有的是`segments`带`words`，有的直接返回`word-level timing`。

**教训**：使用前先检查API版本，确认输出格式后再写解析逻辑。或者用`WordLevelTiming`类专门获取词级时间戳。

---

### 坑7：音频切点计算

**问题**：删除音频片段时，`trim_wav([(2.5, 7.50)])`表示"保留2.5-7.5秒"，不是"删除2.5-7.5秒"。理解错了导致音频时长和预期不符。

**教训**：
- `trim_wav`函数是保留指定区间，删除其他部分
- 操作前先确认函数的语义
- 用最终时长反推验证

## 四、字幕分段规则（可复用）

```
断句优先级：
1. 问句结束于"？"→ 单独成组
2. 称呼（2-3字人名等）→ 可单独成组
3. 语气词"啊" → 可单独成组
4. 静音超过0.2秒 → 断点
5. 标点符号（，。？！）→ 辅助断点

字数限制：
- 硬上限：10字/组
- 低于5字的短句：如果前一句已达8-10字，则合并；否则可单独

不要做的：
- 不要把TPE这样的专有名词分开
- 不要把"一吨多少钱"分开
- 不要强行凑10字
```
