# NC-001 拍摄清单 - 脚本1（门市报价型）

## 任务信息

- 脚本：脚本1-门市报价型.md
- 主题：客户一上来就问价格，我反而不敢报
- 类型：门市部讲解型
- 拍摄地：樟木头塑胶城 - 嘉洋橡塑门市部
- 预计时长：45秒 - 1分钟
- 截止：待定（确认拍摄时间后填入）

---

## 场景准备清单

### 场景布置
| 项目 | 要求 | 状态 |
|------|------|------|
| 门市部背景 | 整洁、产品货架入镜 | ⬜ 待确认 |
| 光线 | 充足，自然光或补光均可 | ⬜ 待确认 |
| 样品摆设 | 3-5个不同TPE应用样品（玩具、汽车件、密封件、仿真花等） | ⬜ 待准备 |
| 收音设备 | 外接麦克风（非手机直录） | ⬜ 待确认 |
| 环境噪音 | 风扇/空调声是否需要处理 | ⬜ 待确认 |

## 分镜头拍摄清单

### 镜头 1【开场钩子】0:00-0:08

| 项目 | 内容 |
|------|------|
| 机位 | 近景/特写，唐姐上半身 |
| 景别 | 胸部以上 |
| 拍摄方向 | 正面对镜头 |
| 动作要点 | 微微摇头叹气，嘴角带点无奈的笑 |
| 口播 | "客户一上来就问我，'唐姐，你家TPE多少钱一吨？' 我说，你先别问价格。" |
| 情绪 | 有态度、不讨好、有点小傲气 |
| 重拍条件 | 笑得太假/语气太温柔/不像真实反应 |
| 建议条数 | 3-5条，选最佳 |

---

### 镜头 2【核心观点输出】0:08-0:25

| 项目 | 内容 |
|------|------|
| 机位 | 中景，上半身+手部动作 |
| 景别 | 胸部至腰部 |

| 动作要点 | 边说边用手势强调重点，眼神认真 |

| 重拍条件 | 手势太少/眼神飘/语气像背台词 |
| 建议条数 | 2-3条 |
