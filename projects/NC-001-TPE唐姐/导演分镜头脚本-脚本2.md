| 项目 | 内容 |

| 主题 | 同样叫TPE，为什么客户用出来差别会这么大 |

## 整体拍摄要求

1. **拍摄顺序：** 按分镜头序号从1到5依次拍摄
2. **每条重拍次数：** 镜头1建议3-5条，其余2-3条，选最佳保一条
3. **设备要求：** 1080P以上，4K更佳；手机拍摄需稳定器
4. **收音要求：** 外接麦克风，禁止手机/相机内置收音
5. **画面风格：** 真实感，不开美颜，自然光或专业补光
6. **横竖选择：** 抖音竖屏（9:16），快手同步
7. **样品要求：** 本集关键道具，需要准备"好差两组TPE样品"做对比展示

---

## 关键道具说明

**样品A（优质TPE）：** 颜色均匀、触感好、成型稳定
**样品B（劣质TPE）：** 颜色不均、触感粗糙、易碎/易裂
（可用同一应用场景的两块实际样品对比，如TPE玩具件或TPE鞋底料）

## 摄影师注意事项（全部）

### 设备设置
- [ ] 分辨率：1920×1080（竖屏9:16）以上
- [ ] 帧率：30fps或60fps均可
- [ ] 稳定器：手机拍摄必须使用
- [ ] 对焦：设置为"脸部优先"，切换到样品时要手动对焦到样品
- [ ] 曝光：锁定曝光

### 收音设备
- [ ] 外接麦克风（领夹麦或枪式麦）已连接并测试
- [ ] 录音电平：录制前测试音量
- [ ] 备用电池：麦克风备用电池已准备

### 样品准备（本集关键道具）
- [ ] 样品A（优质TPE）：全新料、颜色均匀、触感好、成型漂亮
- [ ] 样品B（劣质TPE）：回料多或掺杂质、颜色不均、断面粗糙、易碎
- [ ] 两组样品需为**同一应用场景**（如都是TPE玩具件，或都是TPE鞋底料），否则对比没有说服力
- [ ] 样品提前用布/纸隔开，镜头1展示时有神秘感
- [ ] 样品数量：各准备2-3个，拍摄中可能损坏/污染

### 拍摄环境
- [ ] 桌面整洁：拍摄区域只放对比样品，无杂物
- [ ] 光线：两侧补光，避免样品反光严重或看不清楚
- [ ] 背景：门市部其他区域虚化，焦点在样品

### 唐姐状态
- [ ] 本集唐姐需要有"揭秘感"和"专业底气"，语气比脚本1更自信
- [ ] 镜头1要有悬念感，是"你知道为什么吗"的口气，不是"我要教你"的口气
- [ ] 镜头3是核心干货段落，语速中等偏慢，不要急

### 素材管理
- [ ] 素材命名：`NC001_L{镜头号}_V{版本号}`，如 NC001_L2_V1
- [ ] 拍摄完毕后检查所有素材是否完整播放
- [ ] 收音质量：回放确认声音清晰

## 导演备注（红华编导）

1. **本集核心：** 样品对比是门市部独有的内容资产，工厂拍不了这个。强调"真实性"，样品就是唐姐平时卖货时真实遇到的案例
2. **对比要有冲击力：** 劣质样品要真的"差"，掰得断、断面糙；优质样品要真的好，有韧性、均匀密实。不要演戏
3. **情绪节奏：** 开场悬念感（像揭秘）→ 中段专业干货（像上课）→ 结尾亲和（像朋友）
4. **前置联动：** 脚本1是"问价格"，脚本2是"价格背后的差异"，两集可做成系列，让观众有追看理由
