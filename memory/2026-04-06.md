## Step 1 + Step 2 经验总结（EP01实战）

### Step 1：从原始视频提取音频

**核心原则：**
- 一切从原始视频文件（.MOV/.MP4）提取，不要用中间文件
- 采样率16000Hz、单声道、pcm_s16le格式
- 如果内容来自多个原始视频文件，分别处理再拼接

**EP01实际数据：**
- L1原始：L1_MASTER.MOV（HEVC编码，实为竖屏1080x1920）
- L2原始：L2.MOV
- L3原始：L3.MOV
- L4原始：L4.MOV
- L5原始：L5.MOV

**坑：HEVC编码MOV的ffprobe元数据可能不准确**  
ffprobe显示可能是1920x1080（横屏），但实际截帧确认为1080x1920（竖屏）。  
**每次必须截帧验证实际画面方向**，不能只看ffprobe输出。

### Step 2：完整转写 + 分析 + 切点确定

**必须用 word_timestamps=True，不能用 segment 时间**
- segment时间会遗漏孤立语气词（"3"、"2"、"1"、"好"）
- word级时间才能准确定位每个字

**判断开头问题的4种类型：**

| 类型 | 特征 | 处理方法 |
|------|------|---------|
| A: 321倒计时 | 连续单字3-2-1+开始 | 找到倒计时后第一个有效字，-0.5s |
| B: 孤立语气词 | 开头单独一个字，后面>1s才有下一个 | 删除孤立词，-0.5s |
| C: 静音开头 | 开头超过1s的无声段 | 找到第一个有字的位置，-0.5s |
| D: 正常开头 | 直接从内容开始 | 直接用第一个字时间，-0.5s |

**尾部判断：**
- 最后一个字说完 + 0.5s
- 如果最后一个字在8.72s，结尾切点设为9.22s

## 字幕烧录经验（EP01）

### 成功参数（已验证）
- 格式：SRT（不要用ASS）
- 烧录方式：ffmpeg subtitles滤镜 + force_style
- 字体：Noto Sans CJK SC
- 字号：FontSize=20
- 颜色：PrimaryColour=&H00FFFFFF（白色）
- 描边：OutlineColour=&H00000000（黑色），Outline=2
- 位置：Alignment=2（底部居中），MarginV=60

### 踩过的坑
1. **不要混用SRT和ASS**：ASS需要PlayResY/PlayResX定义坐标系统，和SRT subtitles滤镜不同
2. **不要同时改多个参数**：先在空白视频上测试，OK后再烧录原视频
3. **MarginV的规律**：20=很下，60=中间偏下，250=顶部。竖屏1920高度，MarginV=60大概在底部1/4位置
4. **ffmpeg subtitles滤镜force_style语法**：多个参数用逗号分隔，不要有空格

### 烧录命令模板
```bash
ffmpeg -i 原视频.mp4 \
  -vf "subtitles=字幕.srt:force_style='FontName=Noto Sans CJK SC,FontSize=20,PrimaryColour=&H00FFFFFF,OutlineColour=&H00000000,Outline=2,Alignment=2,MarginV=60'" \
  -c:a copy -y 输出.mp4
```
