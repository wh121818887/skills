# 句内重复检测

## 定义

一个词或短语在句子中间重复出现，形成 A+中间+A 模式。

## 模式识别

```
A + [中间内容] + A

示例：
"好我们接下来好我们接下来做" → 好我们接下来 [好我们接下来] 做
"所以不管你是说所以不管你是说做玩具" → 所以不管你是说 [所以不管你是说] 做玩具
```

## 检测逻辑

```python
def detect_repeated_phrase(text):
    """检测句内重复短语（A+中间+A模式）"""
    words = text.split()
    n = len(words)
    
    for i in range(n):
        for j in range(i+2, n):  # 至少间隔1个词
            # 检查words[i:j]是否与words[j:]的开头相同
            phrase = ' '.join(words[i:j])
            remaining = ' '.join(words[j:])
            if remaining.startswith(phrase):
                # 找到重复，删除前一个
                return (i, j, phrase)
    return None
```

## 案例

| 原句 | 重复部分 | 删除 |
|------|---------|------|
| "好我们接下来好我们接下来做" | 好我们接下来 | 删除第一个"好我们接下来" |
| "所以不管你是说所以不管你是说做玩具" | 所以不管你是说 | 删除第一个"所以不管你是说" |

## 与重复句的区别

- **句内重复**：同一短语在句内重复（中间隔了一些词）
- **重复句**：相邻两句开头相同（整句级别）

## 处理原则

检测到后标记，删前保后（删除第一个重复的短语，保留后半部分）。
