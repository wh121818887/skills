# 重复句检测

## 定义

相邻句子（被静音分隔）开头相同 ≥5字，通常是说错后重说。

## 核心原则

**先分句，再比对**：
- ✓ 正确：按静音切分句子 → 比对相邻句子开头 → 整句删除
- ✗ 错误：逐字扫描 → 发现重复片段 → 只删片段

## 检测逻辑

```python
# 相邻句子比对
if curr.text[:5] == next.text[:5]:  # 开头≥5字相同
    shorter = curr if len(curr.text) <= len(next.text) else next
    mark_for_deletion(shorter)  # 删除整句，不只是重复部分

# 隔一句比对（中间是残句时）
if mid.text.length <= 5:  # 中间是残句
    if curr.text[:5] == next.text[:5]:
        mark_for_deletion(curr)   # 删前句
        mark_for_deletion(mid)    # 删残句
```

## 案例

| 前句 | 后句 | 删除 |
|------|------|------|
| "这是我剪出来的一个案例" | "这是我剪出来的一个案例" | 前句（完全重复） |
| "我用TPE材料做一个样品介绍" | "所以我用TPE材料做一个样品介绍" | 前句 |
| "第二个是耐候性测试第二个" | "第二个是耐候性测试" | 前句 |
| "好我们接下来开始怎么去" | "好我们接下来开始怎么去做" | 前句 |

## 隔一句重复（中间有残句）

```
句A: "具体怎么操作呢"
残句: "那个"           ← 中间隔了残句
句B: "具体怎么操作呢我先"

→ 删 句A + 残句
```

## 多次重复

连续说 3 次以上，删除所有不完整的，保留最后完整的：
```
"以前呢我会把所有的技能"      → 删
"以前呢我会把所有的功能做"    → 删
"以前呢我会把所有的功能做都"  → 删
"以前呢我会把所有的功能都做成一个大的系统" → 保留
```

## 易错点

```
❌ 逐字扫描，只发现局部重复片段
✓ 先分句，比对整句开头，删除整句

❌ 只比对相邻句子
✓ 也要比对隔一句（中间可能是残句）
```
