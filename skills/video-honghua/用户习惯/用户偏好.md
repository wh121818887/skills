# 用户偏好

## 字幕位置

- 竖屏视频字幕：底部居中，Alignment=2
- 不要乱调MarginV，已验证可用

## 语气词处理

- 保留适量"嗯"作为过渡，不要全删

## 专有名词（已验证正确写法）

| 正确写法 | 常见错误 |
|---------|---------|
| TPE | TB-1（错误） |
| 耐候性 | 耐后性（同音字错误） |
| 汽车内饰 | 汽车内舍（同音字错误） |
| 密封件 | 密封圈（用词差异） |
| 样板 | 样品（部分地区用词） |
| 报价 | 报介（语音识别错误） |

## 视频参数

- 分辨率：1080x1920（竖屏）
- 字幕字体：Noto Sans CJK SC
- 字幕大小：18px
- 帧率：30fps

## 删除偏好

- 321倒计时：必须删
- 开场废话：必须删
- 语气词：根据位置决定，句首可删，句中保留
- 重复句：删前保后
- 残句：整句删除
