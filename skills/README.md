## 贡献指南

新增skill时：
1. 在 `skills/` 目录下创建 `{skill-name}/SKILL.md`
2. 包含完整的SOP、踩坑记录、参数模板
3. 描述清楚触发关键词
4. 提交后推送到仓库

改进现有skill时：
1. 使用自进化机制记录反馈
2. 把规则整合到正文，不只是往末尾加
3. 反馈记录只记事件，不重复规则
