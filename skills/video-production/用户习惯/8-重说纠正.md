# 重说纠正

## 定义

说错后立即纠正，删除前面错误的部分。

## 三种模式

### 1. 部分重复

前后词语有重叠但不完全相同：

| 原文 | 删除 |
|------|------|
| 你再关你关掉 | "你再关" |
| 怎么让它去去有个更大的 | "怎么让它去" |
| 因为因为TPE材料 | "因为" |

### 2. 否定纠正

用否定词纠正刚说的：

| 原文 | 删除 |
|------|------|
| 它是它不是 | "它是" |
| 可以不可以 | "可以" |
| 我觉得我觉得不对 | "我觉得" |

### 3. 词被打断

词说一半 + 静音 + 重说完整：

| 原文 | 删除 |
|------|------|
| 依赖[静]依赖关系 | "依赖[静]" |
| 所以[静]所以TPE | "所以[静]" |
| 材料材[静]材料分析 | "材料材[静]" |

## 检测逻辑

```python
# 部分重复：找相邻词的公共前缀
def detect_partial_repeat(words):
    for i in range(len(words) - 1):
        curr = words[i]['text']
        next_text = words[i+1]['text']
        # 检查curr是否是next的开头
        if next_text.startswith(curr) and curr != next_text:
            # 前者是后者的开头 → 删除前者
            mark_for_deletion(words[i])

# 否定纠正：检测"是/可以/要"后接"不X"
def detect_negation(words):
    negation_words = ['不', '没', '别']
    for i in range(len(words) - 1):
        curr = words[i]['text']
        next_text = words[i+1]['text']
        if curr in ['是', '可以', '要', '会', '能'] and next_text.startswith(tuple(negation_words)):
            mark_for_deletion(words[i])
```

## 与重复句的区别

- **重复句**：相邻句子开头完全相同
- **重说纠正**：说错后立即用正确内容纠正（否定或补充）
