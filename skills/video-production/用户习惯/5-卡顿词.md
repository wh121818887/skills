# 卡顿词

## 定义

重复同一个词两次以上，形成卡顿感。

## 常见卡顿词

| 类型 | 示例 |
|------|------|
| 双字重复 | 那个那个、就是就是、这个这个 |
| 三字重复 | 那个那个那个 |
| 混合 | 这个这个这个、就是就是就是 |

## 检测逻辑

```python
import re

def detect_stutter(text):
    """检测卡顿词：重复同一个词"""
    # 双字重复：这个这个、那个那个
    pattern = r'(.{1,3})\1{1,}'
    matches = re.findall(pattern, text)
    return matches

# 示例
# "那个那个客户" → 匹配到"那个那个"，标记删除"那个"部分
```

## 处理方式

标记但不自动删，由用户确认。

原因：有些卡顿可能是表达习惯，不一定都要删。

## 边界情况

```
"那个那个"（单独）→ 删
"客户一上来就问那个那个价格" → 删"那个那个"，保留前后
"那个"（单独出现）→ 不算卡顿，不处理
```

## 与重复句的区别

- **卡顿词**：同一词连续重复（AA模式）
- **重复句**：句子级别开头相同（A句开头 = B句开头）
