# 连续语气词

## 定义

连续出现多个语气词，形成语气词+语气词模式。

## 常见组合

| 类型 | 示例 |
|------|------|
| 双语气词 | 嗯啊、啊呃、嗯嗯、呃呃 |
| 多语气词 | 嗯嗯嗯、啊啊啊、呃呃呃 |
| 混合 | 嗯啊呃、啊啊啊呃 |

## 检测逻辑

```python
filler_words = ['嗯', '啊', '哎', '诶', '呃', '额', '唉', '哦', '噢', '呀', '欸']

def detect_consecutive_fillers(words):
    """检测连续语气词"""
    consecutive = []
    current = []
    
    for w in words:
        if w['text'] in filler_words:
            current.append(w)
        else:
            if len(current) >= 2:
                consecutive.append(current)
            current = []
    
    if len(current) >= 2:
        consecutive.append(current)
    
    return consecutive
```

## 处理方式

| 连续数量 | 处理 |
|----------|------|
| 2个 | 可保留1个 |
| 3个以上 | 删除多余，保留1个 |

## 注意事项

- 连续语气词出现在句首 → 可全删
- 连续语气词出现在句中 → 保留1个作为过渡
- 单个语气词 → 参考"语气词检测"规则

## 与语气词检测的区别

- **语气词检测**：处理单个语气词
- **连续语气词**：处理连续出现的多个语气词
