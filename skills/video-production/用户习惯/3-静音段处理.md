# 静音段处理

## 静音阈值

| 场景 | 阈值 | 处理 |
|------|------|------|
| 大句分隔 | ≥0.5s | 断句 |
| 删除标记 | ≥0.3s | 标记删除 |
| 可保留过渡 | <0.2s | 不处理 |

**⚠️ 不要用0.35s以上阈值**，会把多句话合并成一条超长字幕

## 字幕分段用的静音阈值

用 **0.2s 静音阈值 + 标点符号**分段，不要纯标点分。

## 删除边界

```
❌ 错误：只删静音时间段本身
✅ 正确：静音段通常是大句边界，结合前后文判断是否需要删除
```

## 判断流程

1. 检测静音段 ≥ 0.3s
2. 判断静音前后是否是完整句子
3. 如果前句不完整（残句）→ 整句+静音都删
4. 如果前句完整、后句是新话题 → 只删静音，保留前句句尾

## 与断句的关系

静音是断句的重要依据，但：
- 断句只需要标记位置
- 删除需要额外判断语义完整性
